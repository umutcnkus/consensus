Help & Information
What is Consensus Control?

Consensus control is a distributed algorithm where multiple agents agree on a common value (typically position) by exchanging information only with their neighbors in a network graph.

Graph Topologies
  • Ring (Local): Each agent connects to its neighbors in a circle
  • Complete (Global): Every agent connects to every other agent
  • Star: All agents connect through a central hub
  • Path: Agents form a linear chain
  • Random: Connections are randomly distributed
  • Small World: Mostly local connections with some long-range links
How to Use
  • Click on canvas to add agents
  • Use sliders to adjust parameters
  • Enable "Leader Following Mode" and move mouse to guide agents
  • Watch convergence metrics in real-time
Position Spread

Measures the average distance of agents from their center of mass. When all agents reach the same position (perfect consensus), this value becomes zero.
